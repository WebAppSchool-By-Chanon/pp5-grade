# หน้าปก ปพ.5 รายวิชา — สถานะผลการเรียน

- วิชาตัวเลข: อ่านสถานะ ร/มส ที่บันทึกไว้มาแทนเกรดที่คำนวณจากคะแนน ไม่รวมคนเดียวซ้ำในช่องเกรดตัวเลข
- ประถมอ่านสถานะรายปีจาก offering ภาค 1 ซึ่งเป็นจุดบันทึกเดียวกับหน้าสรุปผล; มัธยมอ่านสถานะรายภาคจาก offering ที่เลือก
- ผ่านการประเมิน = เกรด 1, 1.5, 2, 2.5, 3, 3.5, 4 โดยไม่มี ร/มส
- ไม่ผ่านการประเมิน = เกรด 0 หรือ ร หรือ มส
- กรณีข้อมูลเก่ามีทั้ง ร และ มส พร้อมกัน นับ มส เพียงครั้งเดียว
- วิชาที่ใช้ผลผ่าน/ไม่ผ่านแสดงตารางจำนวนนักเรียน ผ่าน ไม่ผ่าน และร้อยละ ไม่แสดงช่องเกรดตัวเลข ร/มส
- ผลกิจกรรมที่ยังไม่ได้บันทึกไม่นับเป็นผ่านหรือไม่ผ่าน
- การเปลี่ยนแปลงนี้เป็นการอ่าน/สรุปบนหน้าปก ไม่แก้คะแนนหรือสถานะที่บันทึกไว้ และไม่ต้องรัน SQL

## การจัดหน้าปก

- ใช้คำว่า “ร้อยละ” ทั้งวิชาตัวเลขและกิจกรรม
- กำหนดความกว้างช่องเกรด 4 ถึง มส เท่ากัน และช่องระดับผลคุณลักษณะ/อ่านคิดเขียนเท่ากัน ด้วย fixed table layout และ colgroup
- ลำดับลงนาม: ครูผู้สอน → หัวหน้างานวัดและประเมินผล → หัวหน้าวิชาการ
- เมื่อไม่มีชื่อหัวหน้างานวัดผล (รวมช่องว่างล้วน) ซ่อนทั้งบล็อก เหลือสองช่องลงนามกว้างเท่ากัน
- เมื่อไม่มีชื่อรอง ผอ. (รวมช่องว่างล้วน) ไม่แสดงรองฯ และจัดช่อง ผอ. กึ่งกลาง
