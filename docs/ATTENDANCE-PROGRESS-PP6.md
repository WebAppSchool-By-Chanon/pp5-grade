# ความคืบหน้าเวลาเรียนและ ปพ.6 (10 ตุลาคม 2569)

## หน้าหลักสำหรับแอดมิน

- หน้าหลักแสดงปุ่มไปยัง `/attendance-progress` เท่านั้น ไม่อ่านข้อมูลเวลาเรียนเพื่อสรุปอัตโนมัติ
- ปิด prefetch ของปุ่มเพื่อไม่ให้โหลดล่วงหน้าก่อนกด หน้าแยกมีปุ่มกลับหน้าหลัก
- แยกความคืบหน้ารายวันและรายวิชา กดขยายเพื่อดูห้อง/วิชาและเปิดหน้าบันทึก
- ใช้ภาคเรียนปัจจุบัน นักเรียนประถมใช้ทะเบียนทั้งปี มัธยมใช้ทะเบียนภาคปัจจุบัน
- รายวัน: จำนวนช่องที่บันทึก / (นักเรียนปัจจุบัน × วันเปิดเรียนที่เลือกไว้จนถึงวันนี้)
- รายวิชา: จำนวนช่องที่มีข้อมูล / (นักเรียนปัจจุบัน × คาบที่ตั้งวันที่และถึงกำหนดแล้ว)
- ทุกสถานะถือว่าบันทึกแล้ว ไม่ใช่เปอร์เซ็นต์มาเรียน
- รายวิชานับข้อมูลรายวันด้วย โดยค่าที่แก้เฉพาะวิชามีลำดับความสำคัญสูงกว่า และใช้วันที่ชดเชยแทนวันเดิม
- ถ้ายังไม่ตั้งวันสอนครบ จะแจ้งเตือนและคำนวณเฉพาะคาบที่มีวันที่ จึงยังไม่ใช่ความครบถ้วนของทุกคาบ
- ไม่ใช้วันในอนาคต ไม่แสดง 100% เมื่อไม่มีรายการ และไม่ปัด 99.9% เป็น 100%
- เป็นการอ่านข้อมูลเท่านั้น ไม่แก้ข้อมูลเวลาเรียนเก่า ไม่ต้องเพิ่ม SQL

## ปพ.6

- เกรดจำนวนเต็มแสดง 4, 3, 2, 1, 0; เกรดครึ่งระดับยังแสดง เช่น 3.5
- ตัวเลือกแสดงอันดับเปลี่ยนเฉพาะข้อความอันดับ ไม่เปลี่ยนลำดับหน้าเอกสาร
- ลำดับเอกสารใช้เลขที่นักเรียนที่จัดไว้ในห้องเช่นเดิม
- เพิ่มลายเซ็นรองผู้อำนวยการระหว่างครูประจำชั้นกับผู้อำนวยการ เมื่อชื่อรองฯ ในข้อมูลโรงเรียนไม่ว่าง
