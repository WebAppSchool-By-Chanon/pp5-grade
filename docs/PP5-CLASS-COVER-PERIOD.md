# ช่วงเวลาสรุปผลการเรียนบนหน้าปก ปพ.5 รวมชั้น

- เปิดพิมพ์รายงาน ปพ.5 รวมชั้น เลือกชั้น/ห้อง แล้วเลือก “สรุปผลการเรียนบนหน้าปก”
- ประถม: ภาคเรียนที่ 1 / ภาคเรียนที่ 2 / ทั้งปี (ค่าเริ่มต้น)
- มัธยม: ภาคเรียนที่ 1 / ภาคเรียนที่ 2 (เริ่มต้นตามภาคปัจจุบัน) ไม่เฉลี่ยข้ามภาคเพราะตัดสินรายภาค
- ระบุช่วงเวลาในหัวตารางสรุปเกรดและชื่อไฟล์ PDF
- ประถมรายภาคใช้ผลรวมคะแนนของภาคที่เลือก ส่วนทั้งปีใช้ (คะแนนภาค 1 + คะแนนภาค 2) / 2 แล้วเทียบเกณฑ์เกรดโรงเรียน ไม่เฉลี่ยตัวเลขเกรด
- หากไม่มีคะแนนทั้งสองภาคจะไม่นับเป็นเกรด 0; คะแนนที่กรอกเป็น 0 จริงยังนับตามเกณฑ์
- ทั้งปีที่มีเพียงหนึ่งภาคยังหารสองตามหลักเดิมของระบบ หากส่งภาค 1 ก่อนควรเลือกเฉพาะภาค 1
- ตัวเลือกประถมเปลี่ยนเฉพาะตารางสรุปเกรดบนปก: ตารางกิจกรรม การประเมิน และหน้ารายละเอียดอื่นยังคงขอบเขตรายปีเดิม
- มัธยมใช้รายวิชา ทะเบียนนักเรียน และส่วนรายงานอื่นตามภาคที่เลือก เพื่อไม่ผสมข้อมูลต่างภาค
- ไม่เขียนแก้คะแนนหรือผลการเรียนในฐานข้อมูล และไม่ต้องรัน SQL
